# Clone Drove Overhaul
Clone Drove Overhaul (or Overhaul Mod) adds QoL features, new graphics settings, improves UI and adds 300+ user made weapon skins.

This mod uses [Mod-Bot](https://github.com/X606/modbot) to get loaded by Clone drone.

[Mod-Bot page](https://modbot.org/modPreview.html?modID=rAnDomPaTcHeS1)

## Setup
1. Get latest version of Mod-Bot and Clone Drone in the Danger Zone
2. Referenced DLLs from `Clone Drone in the Danger Zone\Clone Drone in the Danger Zone_Data\Managed` folder into `UsedDlls`
3. Everything should be ready to compile.
